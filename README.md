# Турнир CS2 1×1

Готовый сайт для дружеского турнира на 16 игроков:

- четыре GSL-группы по четыре игрока;
- сетка последнего шанса;
- плей-офф и гранд-финал;
- гостевой режим по умолчанию;
- вход организатора по PIN `6996`;
- выбор победителя кнопкой или перетаскиванием;
- выбор карты для каждого матча и стартовых сторон CT/T;
- автоматическое продвижение игроков и очистка зависимых результатов;
- голосование один раз с устройства/сети;
- общие данные для всех гостей и автообновление раз в 5 секунд;
- редактирование названия и имён, сброс сетки и голосов;
- адаптивная версия для компьютера и телефона.

## Быстрый запуск

Нужны Node.js 20.19 или новее и npm.

```bash
npm install
npm run dev
```

Откройте адрес, который напечатает Vite, обычно `http://localhost:5173`.

Локальные серверные переменные лежат в `.env`. Файл исключён из Git. Шаблон — `.env.example`.

Проверка проекта:

```bash
npm run check
```

## Бесплатный хостинг на Netlify

Проект использует Netlify Functions и Netlify Blobs. Поэтому обычный статический хостинг вроде GitHub Pages покажет интерфейс, но не сможет синхронизировать сетку, безопасно проверять PIN и хранить общие голоса.

Самый простой вариант:

1. Создайте Git-репозиторий и загрузите эту папку на GitHub.
2. В Netlify выберите **Add new project → Import an existing project**.
3. Подключите репозиторий. Настройки уже записаны в `netlify.toml`:
   - build command: `npm run build`;
   - publish directory: `dist`;
   - functions directory: `netlify/functions`.
4. В **Project configuration → Environment variables** добавьте:

   ```text
   ADMIN_PIN=6996
   SESSION_SECRET=<длинная случайная строка, минимум 32 символа>
   ```

   Секрет можно сгенерировать командой:

   ```bash
   node -e "console.log(require('node:crypto').randomBytes(32).toString('hex'))"
   ```

5. Запустите deploy. После публикации откройте выданный адрес `*.netlify.app`.

На бесплатном плане Netlify доступны CDN, Functions и Blob storage; для небольшой компании друзей этого достаточно. Официальные материалы: [Vite на Netlify](https://docs.netlify.com/build/frameworks/framework-setup-guides/vite/), [Netlify Functions](https://docs.netlify.com/build/functions/overview/), [Netlify Blobs](https://docs.netlify.com/build/data-and-storage/netlify-blobs/).

## Как пользоваться

### Гость

- видит актуальную сетку;
- может выбрать игрока в разделе «Кто станет чемпионом?»;
- подтверждает голос один раз;
- после голосования видит свой выбор и общие результаты.

### Организатор

1. Нажмите «Войти».
2. Введите `6996`.
3. В строке «Карта» выберите `de_dust2`, `de_mirage`, `de_overpass`,
   `de_inferno`, `de_nuke` или `de_train`.
4. Возле одного из участников выберите CT или T. Сопернику автоматически
   назначится противоположная сторона.
5. Нажмите кубок у победителя либо перетащите игрока в подходящий следующий
   матч.
6. Изменения сохраняются на сервере автоматически и сразу становятся видны
   гостям.

Карту можно назначить заранее, даже пока участники будущего матча ещё не
определены. Стороны становятся доступны, когда известны оба игрока. Если
поменять ранний результат, сайт предупредит, сколько зависимых результатов и
назначений сторон будет очищено.

В «Настройках» можно изменить имена всех 16 игроков, название турнира, начать
сетку заново вместе с картами и сторонами или очистить голоса. PIN меняется без
пересборки сайта — достаточно обновить `ADMIN_PIN` в Netlify и сделать новый
deploy.

## Защита от накрутки

Сервер создаёт атомарную запись голоса с уникальным ключом из HMAC от IP, характеристик устройства и User-Agent. Повторный запрос с тем же ключом отклоняется. Дополнительно на API включены ограничения частоты запросов.

Это разумная защита для дружеского турнира, но не абсолютная идентификация человека: VPN, другое устройство или существенная подмена браузера позволяют обойти ограничение. Для строгого публичного конкурса лучше добавить аккаунты, CAPTCHA или одноразовые коды приглашений.

PIN не попадает в браузерный JavaScript: он проверяется только серверной функцией. После входа сервер выдаёт подписанную `HttpOnly; SameSite=Strict` cookie на 12 часов.

## Структура

```text
src/
  components/        интерфейс сетки, голосования и модальных окон
  data/              стартовые 16 игроков
  lib/bracket.ts     расчёт матчей и продвижения
  lib/api.ts         запросы к серверу
netlify/
  functions/         API входа, состояния и голосов
  lib/               хранение, валидация и безопасность
netlify.toml          настройки сборки и функций
```

Сервер хранит имена, выбранных победителей, карты, стартовые стороны и голоса.
Все участники следующих раундов, места в группах и пьедестал вычисляются из
результатов — устаревшие или невозможные пары не сохраняются.
